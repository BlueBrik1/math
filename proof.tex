\section*{Axiomatic System}

\textbf{Axiom 1 (Infinite Adjunction).}

Beginning with a base set \(P_0\), whenever a set \(P_n\) has been constructed, there exists a fixed distinguished element

\[
a_{n+1}\notin P_n
\]

which has not appeared at any preceding construction stage. Distinct stages use distinct elements. Hence the construction may continue indefinitely.

At this point the subscripts

\[
0,1,2,\ldots
\]

serve only as construction-stage labels. Their arithmetic properties have not yet been assumed or defined.

\textbf{Axiom 2 (Function Well-Definedness).}

A function \(f\:X\to Y\) maps every input \(x\in X\) to exactly one output \(f(x)\in Y\). We denote evaluation by

\[
f(x)\to y.
\]

\textbf{Axiom 3 (Structural Induction).}

Let \(\mathcal C\) be a family generated from a base object \(X_0\) by repeated application of a well-defined function \(f\). If a property holds for \(X_0\), and whenever it holds for a constructed object \(X_n\) it also holds for \(f(X_n)\), then the property holds for every object generated from \(X_0\) by repeated applications of \(f\).

\section*{Definitions and Rules}

\subsection*{1.1 Base Set}

Let

\[
P_0=\varnothing.
\]

The empty set serves as the base representation of the symbol

\[
0.
\]

\subsection*{1.2 Canonical Finite Sets}

Using Axiom 1, define the canonical sets recursively.

Whenever \(P_n\) has already been constructed, define

\[
P_{n+1}=P_n\cup\{a_{n+1}\},
\]

where

\[
a_{n+1}\notin P_n.
\]

Consequently,

\[
P_0=\varnothing,
\]

\[
P_1=\{a_1\},
\]

\[
P_2=\{a_1,a_2\},
\]

\[
P_3=\{a_1,a_2,a_3\},
\]

and so on.

Let \(\mathcal P\) denote the smallest family containing \(P_0\) and closed under this construction.

Thus

\[
\mathcal P=\{P_0,P_1,P_2,P_3,\ldots\}.
\]

Because the element introduced at each stage is fixed, each construction stage has a unique output.

\subsection*{1.3 Output Symbols and the Cardinality Function}

We now assign one output symbol to each construction stage.

Define \(\Theta\) on the canonical family \(\mathcal P\) recursively by

\[
\Theta(P_0)=0,
\]

and whenever \(P_{n+1}\) is the immediate successor of \(P_n\), let \(\Theta(P_{n+1})\) be the next output symbol after \(\Theta(P_n)\).

Accordingly,

\[
\Theta(P_0)=0,
\]

\[
\Theta(P_1)=1,
\]

\[
\Theta(P_2)=2,
\]

\[
\Theta(P_3)=3,
\]

and so on.

Hence, after these symbols have been generated,

\[
\Theta(P_n)=n.
\]

The statement \(\Theta(P_n)=n\) therefore does not use a previously defined arithmetic operation. It associates the symbol generated at stage \(n\) with the canonical set generated at the same stage.

Since each \(P_n\) contains exactly the elements introduced during the first \(n\) nonzero construction stages, \(\Theta(P_n)\) is also the finite cardinality of \(P_n\). Therefore, once the symbols have been constructed, we may write

\[
\Theta(P_n)=|P_n|.
\]

The domain of \(\Theta\) in this construction is \(\mathcal P\), so \(\Theta\) is never required to assign a finite natural-number output to an arbitrary infinite set.

\subsection*{1.4 Successor Function}

Define

\[
\Sigma:\mathcal P\to\mathcal P
\]

by

\[
\Sigma(P_n)=P_n\cup\{a_{n+1}\}=P_{n+1}.
\]

Because \(a_{n+1}\) is fixed at construction stage \(n+1\), \(\Sigma\) maps every canonical set to a unique canonical set and is therefore well-defined.

Applying \(\Sigma\) repeatedly gives

\[
P_0=\varnothing,
\]

\[
\Sigma(P_0)=P_1=\{a_1\},
\]

\[
\Sigma(\Sigma(P_0))=P_2=\{a_1,a_2\},
\]

\[
\Sigma(\Sigma(\Sigma(P_0)))=P_3=\{a_1,a_2,a_3\}.
\]

Evaluating with \(\Theta\),

\[
\Theta(P_0)=0,
\]

\[
\Theta(\Sigma(P_0))=1,
\]

\[
\Theta(\Sigma(\Sigma(P_0)))=2,
\]

\[
\Theta(\Sigma(\Sigma(\Sigma(P_0))))=3.
\]

For any already constructed nonnegative output symbol \(k\), write

\[
\Sigma^k(P)
\]

for \(k\) repeated applications of \(\Sigma\), with

\[
\Sigma^0(P)=P.
\]

\subsection*{1.5 Natural Numbers Definition}

The natural numbers are defined to be exactly the output symbols produced by evaluating \(\Theta\) on the canonical sets:

\[
\mathbb N
=
\{\Theta(P)\mid P\in\mathcal P\}.
\]

Thus

\[
\boxed{
\mathbb N=\{0,1,2,3,\ldots\}.
}
\]

This definition does not require a statement of the form \(k\in\mathbb N\) before \(\mathbb N\) itself has been constructed.

Now that \(\mathbb N\) has been constructed, the evaluation function may be written formally as

\[
\boxed{
\Theta:\mathcal P\to\mathbb N.
}
\]

\section*{Defining Addition}

We define addition using the canonical sets, the successor function \(\Sigma\), and the evaluation function \(\Theta\).

For \(P_1,P_2\in\mathcal P\), define

\[
\boxed{
\Alpha(P_1,P_2)
=
\Theta\left(\Sigma^{\Theta(P_2)}(P_1)\right).
}
\]

Thus \(\Alpha(P_1,P_2)\) is a natural-number symbol, not a set.

We define the ordinary notation \(+\) by

\[
\boxed{
\Theta(P_1)+\Theta(P_2)
:=
\Alpha(P_1,P_2).
}
\]

Therefore,

\[
\Theta(P_1)+\Theta(P_2)
=
\Theta\left(\Sigma^{\Theta(P_2)}(P_1)\right).
\]

\subsection*{Addition by Zero}

Since

\[
\Theta(P_0)=0,
\]

we have

\[
\Alpha(P_1,P_0)
=
\Theta\left(\Sigma^{\Theta(P_0)}(P_1)\right)
=
\Theta(\Sigma^0(P_1))
=
\Theta(P_1).
\]

Hence

\[
\boxed{
\Theta(P_1)+0=\Theta(P_1).
}
\]

Also,

\[
\Alpha(P_0,P_1)
=
\Theta\left(\Sigma^{\Theta(P_1)}(P_0)\right).
\]

By construction, applying \(\Sigma\) to \(P_0\) exactly \(\Theta(P_1)\) times produces \(P_1\). Therefore

\[
\Alpha(P_0,P_1)=\Theta(P_1),
\]

so

\[
\boxed{
0+\Theta(P_1)=\Theta(P_1).
}
\]

\subsection*{Successor Compatibility}

Suppose

\[
\Alpha(P_1,P_2)=\Theta(P_r).
\]

Then

\[
\Sigma^{\Theta(P_2)}(P_1)=P_r.
\]

Since \(\Sigma(P_2)\) contains exactly one more constructed element than \(P_2\),

\[
\Sigma^{\Theta(\Sigma(P_2))}(P_1)
=
\Sigma\left(\Sigma^{\Theta(P_2)}(P_1)\right).
\]

Therefore

\[
\Alpha(P_1,\Sigma(P_2))
=
\Theta\left(
\Sigma\left(\Sigma^{\Theta(P_2)}(P_1)\right)
\right)
=
\Theta(\Sigma(P_r)).
\]

Likewise,

\[
\Sigma^{\Theta(P_1)}(\Sigma(P_2))
=
\Sigma\left(\Sigma^{\Theta(P_1)}(P_2)\right).
\]

Thus taking one successor step in either input produces one successor step in the resulting canonical set.

\subsection*{Commutativity of Addition}

\begin{theorem}

For all \(P_1,P_2\in\mathcal P\),

\[
\Alpha(P_1,P_2)=\Alpha(P_2,P_1).
\]

Consequently,

\[
\Theta(P_1)+\Theta(P_2)=\Theta(P_2)+\Theta(P_1).
\]

\end{theorem}

\begin{proof}

Fix \(P_1\). We use structural induction on \(P_2\).

For the base case,

\[
P_2=P_0.
\]

Then

\[
\Alpha(P_1,P_0)=\Theta(P_1).
\]

Also,

\[
\Alpha(P_0,P_1)
=
\Theta\left(\Sigma^{\Theta(P_1)}(P_0)\right)
=
\Theta(P_1).
\]

Hence

\[
\Alpha(P_1,P_0)=\Alpha(P_0,P_1).
\]

Now assume

\[
\Alpha(P_1,P_2)=\Alpha(P_2,P_1).
\]

Let

\[
P_2'=\Sigma(P_2).
\]

By successor compatibility,

\[
\Alpha(P_1,P_2')
\]

is the output symbol immediately following

\[
\Alpha(P_1,P_2).
\]

Likewise,

\[
\Alpha(P_2',P_1)
\]

is the output symbol immediately following

\[
\Alpha(P_2,P_1).
\]

By the induction hypothesis,

\[
\Alpha(P_1,P_2)=\Alpha(P_2,P_1),
\]

so their immediate successor symbols are equal. Therefore

\[
\Alpha(P_1,P_2')=\Alpha(P_2',P_1).
\]

By structural induction,

\[
\Alpha(P_1,P_2)=\Alpha(P_2,P_1)
\]

for every \(P_2\in\mathcal P\).

\end{proof}

Therefore it is valid to write

\[
\boxed{
\Theta(P_1)+\Theta(P_2)
=
\Theta(P_2)+\Theta(P_1).
}
\]

\subsection*{Example: \(1+2\)}

Let

\[
P_0=\varnothing,
\]

\[
P_1=\Sigma(P_0),
\]

\[
P_2=\Sigma(\Sigma(P_0)).
\]

Then

\[
\Theta(P_1)=1,
\qquad
\Theta(P_2)=2.
\]

Evaluate

\[
\Alpha(P_1,P_2)
=
\Theta\left(\Sigma^{\Theta(P_2)}(P_1)\right).
\]

Since

\[
\Theta(P_2)=2,
\]

we obtain

\[
\Alpha(P_1,P_2)
=
\Theta(\Sigma^2(P_1)).
\]

But

\[
\Sigma^2(P_1)
=
\Sigma(\Sigma(P_1))
=
P_3.
\]

Thus

\[
\Alpha(P_1,P_2)
=
\Theta(P_3)
=
3.
\]

Therefore

\[
1+2=3.
\]

By the commutativity theorem,

\[
\Alpha(P_2,P_1)=\Alpha(P_1,P_2)=3,
\]

so

\[
2+1=3.
\]

Hence

\[
\boxed{
1+2=2+1=3.
}
\]

\section*{Subtraction on Natural Numbers via Element Removal}

We now define subtraction when the result remains nonnegative.

\subsection*{1. Element Removal Function}

Define the removal function \(\Nu\) on every nonempty canonical set by the predecessor rule

\[
\boxed{
\Nu(P_{n+1})=P_n.
}
\]

Here \(n+1\) denotes the immediate next construction-stage label already used in the canonical-set construction. No subtraction operation is being assumed in this definition. Equivalently, \(\Nu\) removes the distinguished element introduced most recently in the canonical construction.

For example,

\[
P_3=\{a_1,a_2,a_3\}.
\]

Then

\[
\Nu(P_3)
=
\{a_1,a_2\}
=
P_2.
\]

Similarly,

\[
\Nu(P_2)=P_1
\]

and

\[
\Nu(P_1)=P_0.
\]

In particular,

\[
\Nu(P_1)=P_0=\varnothing,
\]

and therefore

\[
\Theta(\Nu(P_1))=0.
\]

The rule specifies a unique element to remove, so \(\Nu\) is well-defined.

\subsection*{2. Iterated Removal}

For any natural-number symbol \(k\), define the iteration recursively by

\[
\boxed{
\Nu^0(P)=P.
}
\]

Whenever \(\Nu^k(P)\) has already been constructed and is nonempty, define the next iteration by

\[
\boxed{
\Nu^{k+1}(P)
=
\Nu\left(\Nu^k(P)\right).
}
\]

Thus iterated removal is defined using the already-constructed successor progression of natural-number symbols and does not assume subtraction.

For example,

\[
\Nu^2(P_3)
=
\Nu(\Nu(P_3))
=
\Nu(P_2)
=
P_1.
\]

\subsection*{3. Ordering of Natural Numbers}

Before restricting subtraction, define the order relation \(\leq\).

For canonical sets \(P_1,P_2\), define

\[
\boxed{
\Theta(P_2)\leq \Theta(P_1)
}
\]

to mean that \(P_1\) can be obtained from \(P_2\) by zero or more applications of \(\Sigma\).

Equivalently,

\[
\Theta(P_2)\leq \Theta(P_1)
\]

when there exists a natural-number symbol \(k\) such that

\[
\Sigma^k(P_2)=P_1.
\]

Thus, for example,

\[
1\leq3
\]

because

\[
\Sigma^2(P_1)=P_3.
\]

\subsection*{4. Definition of Natural Subtraction}

Let

\[
\Delta(P_1,P_2)
\]

be defined whenever

\[
\Theta(P_2)\leq \Theta(P_1).
\]

Define

\[
\boxed{
\Delta(P_1,P_2)
=
\Theta\left(
\Nu^{\Theta(P_2)}(P_1)
\right).
}
\]

We then define

\[
\boxed{
\Theta(P_1)-\Theta(P_2)
:=
\Delta(P_1,P_2)
}
\]

whenever

\[
\Theta(P_2)\leq \Theta(P_1).
\]

The restriction guarantees that \(\Nu\) is never required to remove an element from \(P_0\).

\subsection*{5. Example Evaluation}

Let

\[
P_3=\{a_1,a_2,a_3\}
\]

and

\[
P_1=\{a_1\}.
\]

Then

\[
\Theta(P_3)=3
\]

and

\[
\Theta(P_1)=1.
\]

Evaluate

\[
\Delta(P_3,P_1)
=
\Theta\left(\Nu^{\Theta(P_1)}(P_3)\right).
\]

Since

\[
\Theta(P_1)=1,
\]

we have

\[
\Delta(P_3,P_1)
=
\Theta(\Nu(P_3)).
\]

By the definition of \(\Nu\),

\[
\Nu(P_3)=P_2.
\]

Therefore

\[
\Delta(P_3,P_1)
=
\Theta(P_2)
=
2.
\]

Thus

\[
\boxed{
3-1=2.
}
\]

\section*{Constructing Negative Numbers}

Natural-number subtraction as defined above does not yet assign an output to expressions such as

\[
1-2.
\]

We now construct signed integers using ordered pairs of canonical sets.

\subsection*{1. Ordered-Pair Representation}

Take an ordered pair

\[
(P_x,P_y),
\]

where

\[
P_x,P_y\in\mathcal P.
\]

The first component records a positive contribution, and the second component records a negative contribution.

At this stage, however, the symbol ``negative'' describes the role of the second component only. A negative-number symbol such as \(-1\) will be introduced only after the corresponding ordered-pair object has been constructed.

\subsection*{2. Reduction Function}

Define

\[
\Lambda[(P_x,P_y)]
\]

recursively by

\[
\boxed{
\Lambda[(P_x,P_y)]
=
\begin{cases}
\Lambda[(\Nu(P_x),\Nu(P_y))],
&
\Theta(P_x)>0\text{ and }\Theta(P_y)>0,
\\[6pt]
(P_x,P_y),
&
\Theta(P_x)=0\text{ or }\Theta(P_y)=0.
\end{cases}
}
\]

Here

\[
\Theta(P)>0
\]

means simply

\[
P\neq P_0.
\]

Every recursive step removes one element from both components.

Since \(P_x\) and \(P_y\) are finite canonical sets, after finitely many applications of \(\Nu\), at least one component must become \(P_0\).

Therefore \(\Lambda\) always terminates.

Most importantly,

\[
\Lambda
\]

always returns an ordered pair. Its output type does not change during the definition.

\subsection*{3. Reduced Signed Pairs}

A pair

\[
(P_x,P_y)
\]

is called \emph{reduced} if at least one component equals \(P_0\).

Thus every reduced pair has exactly one of the following forms:

\[
(P_n,P_0),
\]

\[
(P_0,P_n),
\]

or

\[
(P_0,P_0).
\]

The function \(\Lambda\) maps every ordered pair of canonical sets to exactly one reduced pair.

\subsection*{4. Signed Integer Notation}

We now introduce notation for these already-constructed reduced pairs.

For a nonzero natural-number symbol \(n\), define the notation

\[
(P_n,P_0)\equiv n.
\]

Define

\[
(P_0,P_0)\equiv0.
\]

Finally, for a nonzero natural-number symbol \(n\), introduce the new notation

\[
\boxed{
(P_0,P_n)\equiv -n.
}
\]

Thus the symbol

\[
-n
\]

is not used to construct the negative integer.

Instead, the ordered pair

\[
(P_0,P_n)
\]

is constructed first, and \(-n\) is then assigned as notation for that object.

The signed integers are therefore the reduced pairs

\[
\boxed{
\mathbb Z
=
\{
\Lambda[(P_x,P_y)]
\mid
P_x,P_y\in\mathcal P
\}.
}
\]

Using the notation above, these objects are written

\[
\mathbb Z
=
\{\ldots,-3,-2,-1,0,1,2,3,\ldots\}.
\]

\subsection*{5. Canonical Representation}

Because \(\Lambda\) removes one element from each side simultaneously, every pair has a unique reduced representative.

For example,

\[
\Lambda[(P_2,P_1)]
=
\Lambda[(\Nu(P_2),\Nu(P_1))]
=
\Lambda[(P_1,P_0)]
=
(P_1,P_0).
\]

Thus

\[
(P_2,P_1)
\]

and

\[
(P_1,P_0)
\]

reduce to the same signed integer.

More generally, two ordered pairs

\[
(P_a,P_b)
\]

and

\[
(P_c,P_d)
\]

represent the same signed integer precisely when

\[
\boxed{
\Lambda[(P_a,P_b)]
=
\Lambda[(P_c,P_d)].
}
\]

Hence signed integers have unique reduced representatives even though unreduced intermediate pairs may differ.

\subsection*{6. Examples}

\textbf{Example 1: \(1-2\).}

Take

\[
P_1=\{a_1\}
\]

and

\[
P_2=\{a_1,a_2\}.
\]

Evaluate

\[
\Lambda[(P_1,P_2)].
\]

Since both components are nonempty,

\[
\Lambda[(P_1,P_2)]
=
\Lambda[(\Nu(P_1),\Nu(P_2))].
\]

Using

\[
\Nu(P_1)=P_0
\]

and

\[
\Nu(P_2)=P_1,
\]

we obtain

\[
\Lambda[(P_1,P_2)]
=
\Lambda[(P_0,P_1)].
\]

Because the first component is now \(P_0\),

\[
\Lambda[(P_0,P_1)]
=
(P_0,P_1).
\]

By the signed notation introduced above,

\[
(P_0,P_1)\equiv-1.
\]

Therefore

\[
\boxed{
1-2=-1.
}
\]

\textbf{Example 2: \(2-1\).}

Evaluate

\[
\Lambda[(P_2,P_1)].
\]

Since both components are nonempty,

\[
\Lambda[(P_2,P_1)]
=
\Lambda[(\Nu(P_2),\Nu(P_1))].
\]

Thus

\[
\Lambda[(P_2,P_1)]
=
\Lambda[(P_1,P_0)]
=
(P_1,P_0).
\]

By signed notation,

\[
(P_1,P_0)\equiv1.
\]

Therefore

\[
\boxed{
2-1=1.
}
\]

\textbf{Example 3: \(2-2\).}

Evaluate

\[
\Lambda[(P_2,P_2)].
\]

First,

\[
\Lambda[(P_2,P_2)]
=
\Lambda[(\Nu(P_2),\Nu(P_2))]
=
\Lambda[(P_1,P_1)].
\]

Both components remain nonempty, so

\[
\Lambda[(P_1,P_1)]
=
\Lambda[(\Nu(P_1),\Nu(P_1))]
=
\Lambda[(P_0,P_0)].
\]

The pair is now reduced, giving

\[
\Lambda[(P_0,P_0)]
=
(P_0,P_0).
\]

Since

\[
(P_0,P_0)\equiv0,
\]

we obtain

\[
\boxed{
2-2=0.
}
\]

\section*{Addition and Subtraction of Signed Pairs}

We now define arithmetic on signed-pair representations. The inputs may be reduced or unreduced; the final application of \(\Lambda\) produces the unique reduced representative.

Let

\[
(P_a,P_b)
\]

and

\[
(P_c,P_d)
\]

be signed-pair representations.

The positive contributions are represented by

\[
P_a
\quad\text{and}\quad
P_c,
\]

while the negative contributions are represented by

\[
P_b
\quad\text{and}\quad
P_d.
\]

\subsection*{Signed Addition}

The combined positive count is

\[
\Alpha(P_a,P_c).
\]

The corresponding canonical set is

\[
\Sigma^{\Alpha(P_a,P_c)}(P_0).
\]

Likewise, the combined negative count is

\[
\Alpha(P_b,P_d),
\]

with corresponding canonical set

\[
\Sigma^{\Alpha(P_b,P_d)}(P_0).
\]

Therefore define

\[
\boxed{
\Gamma
\left(
(P_a,P_b),(P_c,P_d)
\right)
=
\Lambda\left[
\left(
\Sigma^{\Alpha(P_a,P_c)}(P_0),
\Sigma^{\Alpha(P_b,P_d)}(P_0)
\right)
\right].
}
\]

The result is a reduced signed pair. We therefore define ordinary addition notation for signed-pair representations by

\[
\boxed{
(P_a,P_b)+(P_c,P_d)
:=
\Gamma\left((P_a,P_b),(P_c,P_d)\right).
}
\]

\subsection*{Signed Additive Inverse}

For a signed pair

\[
(P_c,P_d),
\]

define its additive inverse by exchanging its two components:

\[
\boxed{
-(P_c,P_d):=(P_d,P_c).
}
\]

This is valid because the component that formerly contributed positively now contributes negatively, and the component that formerly contributed negatively now contributes positively.

For example,

\[
-(P_2,P_0)
=
(P_0,P_2),
\]

so the additive inverse of \(2\) is represented by

\[
(P_0,P_2)\equiv-2.
\]

Similarly,

\[
-(P_0,P_2)
=
(P_2,P_0),
\]

so the additive inverse of \(-2\) is \(2\).

\subsection*{Signed Subtraction}

Subtraction is addition of the additive inverse.

Thus

\[
(P_a,P_b)-(P_c,P_d)
\]

is defined as

\[
(P_a,P_b)+(P_d,P_c).
\]

Therefore

\[
\boxed{
\Pi
\left(
(P_a,P_b),(P_c,P_d)
\right)
=
\Lambda\left[
\left(
\Sigma^{\Alpha(P_a,P_d)}(P_0),
\Sigma^{\Alpha(P_b,P_c)}(P_0)
\right)
\right].
}
\]

We therefore define ordinary subtraction notation for signed-pair representations by

\[
\boxed{
(P_a,P_b)-(P_c,P_d)
:=
\Pi\left((P_a,P_b),(P_c,P_d)\right).
}
\]

\subsection*{1. Adding Same Signs: \((-2)+(-1)\)}

The inputs are

\[
(P_0,P_2)
\]

and

\[
(P_0,P_1).
\]

The new positive count is

\[
\Alpha(P_0,P_0)=0.
\]

Therefore

\[
P_{\mathrm{pos}}
=
\Sigma^0(P_0)
=
P_0.

\section*{Non-Unique Signed-Pair Representations}

The signed-pair construction admits infinitely many unreduced representations of the same signed integer.

Let

\[
(P_a,P_b)
\]

be any signed-pair representation, and let

\[
P_v\in\mathcal P.
\]

Construct the shifted pair

\[
\left(
\Sigma^{\Theta(P_v)}(P_a),
\Sigma^{\Theta(P_v)}(P_b)
\right).
\]

Since

\[
\Theta(P_v)=v,
\]

and applying \(\Sigma\) exactly \(v\) times to a canonical set \(P_a\) produces \(P_{a+v}\), we have

\[
\Sigma^{\Theta(P_v)}(P_a)=P_{a+v}
\]

and

\[
\Sigma^{\Theta(P_v)}(P_b)=P_{b+v}.
\]

Hence the shifted pair may be written

\[
\boxed{
\left(
\Sigma^{\Theta(P_v)}(P_a),
\Sigma^{\Theta(P_v)}(P_b)
\right)
=
(P_{a+v},P_{b+v}).
}
\]

\subsection*{Invariance Under Equal Shifting}

\begin{theorem}

For every \(P_a,P_b,P_v\in\mathcal P\),

\[
\boxed{
\Lambda[(P_a,P_b)]
=
\Lambda[(P_{a+v},P_{b+v})].
}
\]

Equivalently,

\[
\boxed{
\Lambda[(P_a,P_b)]
=
\Lambda\left[
\left(
\Sigma^{\Theta(P_v)}(P_a),
\Sigma^{\Theta(P_v)}(P_b)
\right)
\right].
}
\]

\end{theorem}

\begin{proof}

The pair

\[
(P_{a+v},P_{b+v})
\]

contains the same additional contribution \(v\) in both components.

By the definition of \(\Lambda\), whenever both components are nonempty, one application of \(\Nu\) is made to each component simultaneously.

Applying this simultaneous removal \(v\) times gives

\[
\Lambda[(P_{a+v},P_{b+v})]
=
\Lambda[(P_a,P_b)].
\]

Therefore adding the same canonical contribution to both components does not change the reduced signed integer represented by the pair.

Hence

\[
\boxed{
\Lambda[(P_{a+v},P_{b+v})]
=
\Lambda[(P_a,P_b)].
}
\]

\end{proof}

Thus a single signed integer does not have only one possible unreduced representation.

For example,

\[
(P_a,P_b),
\]

\[
(P_{a+1},P_{b+1}),
\]

\[
(P_{a+2},P_{b+2}),
\]

and, more generally,

\[
(P_{a+v},P_{b+v})
\]

all reduce to the same signed integer.

Because the canonical family

\[
\mathcal P
=
\{P_0,P_1,P_2,P_3,\ldots\}
\]

contains infinitely many canonical sets, there are infinitely many possible choices of \(P_v\), and therefore infinitely many unreduced representations of the same signed integer.

\section*{Non-Unique Input Representations for Signed Addition}

Consider

\[
\Gamma
\left(
(P_a,P_b),(P_c,P_d)
\right).
\]

Let

\[
P_v,P_w\in\mathcal P.
\]

Independently shift the two input pairs by \(P_v\) and \(P_w\), respectively.

The first pair becomes

\[
\left(
\Sigma^{\Theta(P_v)}(P_a),
\Sigma^{\Theta(P_v)}(P_b)
\right),
\]

and the second becomes

\[
\left(
\Sigma^{\Theta(P_w)}(P_c),
\Sigma^{\Theta(P_w)}(P_d)
\right).
\]

Therefore,

\[
\boxed{
\begin{aligned}
&
\Gamma
\left(
(P_a,P_b),(P_c,P_d)
\right)
\\[4pt]
&=
\Gamma
\left(
\left(
\Sigma^{\Theta(P_v)}(P_a),
\Sigma^{\Theta(P_v)}(P_b)
\right),
\left(
\Sigma^{\Theta(P_w)}(P_c),
\Sigma^{\Theta(P_w)}(P_d)
\right)
\right).
\end{aligned}
}
\]

Using the canonical-set notation, this is equivalently

\[
\boxed{
\Gamma
\left(
(P_a,P_b),(P_c,P_d)
\right)
=
\Gamma
\left(
(P_{a+v},P_{b+v}),
(P_{c+w},P_{d+w})
\right).
}
\]

\begin{theorem}

For every

\[
P_a,P_b,P_c,P_d,P_v,P_w\in\mathcal P,
\]

the equality

\[
\boxed{
\Gamma
\left(
(P_a,P_b),(P_c,P_d)
\right)
=
\Gamma
\left(
(P_{a+v},P_{b+v}),
(P_{c+w},P_{d+w})
\right)
}
\]

holds.

\end{theorem}

\begin{proof}

By the preceding theorem,

\[
\Lambda[(P_{a+v},P_{b+v})]
=
\Lambda[(P_a,P_b)]
\]

and independently,

\[
\Lambda[(P_{c+w},P_{d+w})]
=
\Lambda[(P_c,P_d)].
\]

Thus each shifted pair represents exactly the same signed integer as its corresponding original pair.

The definition of signed addition combines the positive components, combines the negative components, and then applies \(\Lambda\).

Adding \(v\) to both components of the first pair contributes the same additional amount to the positive and negative sides.

Likewise, adding \(w\) to both components of the second pair contributes the same additional amount to the positive and negative sides.

These equal contributions cancel under \(\Lambda\).

Therefore

\[
\Gamma
\left(
(P_{a+v},P_{b+v}),
(P_{c+w},P_{d+w})
\right)
=
\Gamma
\left(
(P_a,P_b),(P_c,P_d)
\right).
\]

\end{proof}

\subsection*{Infinitely Many Addition Representations}

Since \(P_v\) and \(P_w\) may each be chosen independently from the infinite family

\[
\mathcal P,
\]

a single signed addition may be represented by infinitely many different input tuples.

Thus

\[
\Gamma
\left(
(P_a,P_b),(P_c,P_d)
\right)
\]

may equivalently be evaluated using

\[
\Gamma
\left(
(P_{a+v},P_{b+v}),
(P_{c+w},P_{d+w})
\right)
\]

for arbitrary

\[
v,w\in\mathbb N.
\]

For example, all of the following produce the same signed output:

\[
\Gamma
\left(
(P_a,P_b),(P_c,P_d)
\right),
\]

\[
\Gamma
\left(
(P_{a+1},P_{b+1}),
(P_{c+1},P_{d+1})
\right),
\]

\[
\Gamma
\left(
(P_{a+5},P_{b+5}),
(P_{c+9},P_{d+9})
\right),
\]

and

\[
\Gamma
\left(
(P_{a+v},P_{b+v}),
(P_{c+w},P_{d+w})
\right)
\]

for arbitrary \(v\) and \(w\).

Consequently, the mapping from such input representations to the reduced signed output is not injective.

That is, if only the final reduced output

\[
P_{\mathrm{out}}
=
\Gamma
\left(
(P_{a+v},P_{b+v}),
(P_{c+w},P_{d+w})
\right)
\]

is known, the output alone does not uniquely determine the values of

\[
v
\qquad\text{and}\qquad
w.
\]

Nor does it uniquely determine the particular unreduced input pairs used in the computation.

There are infinitely many distinct admissible input representations that may correspond to the same signed output.

This is a many-to-one property of the representation system.

It should not by itself be interpreted as a proof of computational hardness or as a statement concerning the complexity-theoretic question \(P\) versus \(NP\). Rather, it establishes that information about the particular input representation is lost when the inputs are reduced to a single signed result.

(P_c,P_d)

(P_{c+w},P_{d+w})

also represent the same signed integer.

Therefore,

\[
\boxed{
\Pi
\left(
(P_a,P_b),(P_c,P_d)
\right)
=
\Pi
\left(

Equivalently,

\[
\boxed{
\begin{aligned}
&
\Pi
\left(

\\[4pt]
&=
\Pi
\left(
\left(
\Sigma^{\Theta(P_v)}(P_a),

\section*{Input-to-Output Representation Expansion}

A standard signed addition

\[
\Gamma
\left(
(P_a,P_b),(P_c,P_d)
\right)
\]

requires four canonical input sets:

\[
P_a,\qquad P_b,\qquad P_c,\qquad P_d.
\]

Under the non-unique representation construction, two additional canonical sets may be chosen:

\[
P_v
\qquad\text{and}\qquad
P_w.
\]

These determine the independent shifts applied to the two signed input pairs.

The complete representation may therefore depend upon the six canonical sets

\[
\boxed{
P_a,\;
P_b,\;
P_c,\;
P_d,\;
P_v,\;
P_w.
}
\]

while the function ultimately returns a single signed-integer value, represented canonically by one reduced signed pair.

If one merely counts the six selected canonical-set parameters against the one resulting signed value, the representation has the bookkeeping description

\[
\boxed{6:1}
\]

of input-set parameters to output value:

\[
\boxed{
6\text{ selected canonical-set parameters}
\longrightarrow
1\text{ signed output value}.
}
\]

This is not a statement that the function has exactly six possible inputs or six preimages for each output. The preceding results show the opposite: infinitely many distinct shifted input representations can produce the same signed output.

The sets \(P_v\) and \(P_w\) are optional in the sense that choosing

\[
P_v=P_0
\qquad\text{and}\qquad
P_w=P_0
\]

returns the original unshifted representation.

Therefore the ordinary signed operation is contained as the special case

\[
v=w=0.
\]

The additional sets \(P_v\) and \(P_w\) do not alter the resulting signed value. They alter only the particular unreduced representation used to obtain that value.

This distinction between the represented value and the particular representation used to encode that value will be relevant when considering later applications involving concealed or randomized representations.

\section*{Defining Multiplication}

We now define multiplication on signed integers using the signed-pair representation already constructed.

Let

\[
(P_a,P_b)
\]

and

\[
(P_c,P_d)
\]

be signed-pair representations.

First reduce both pairs:

\[
\Lambda[(P_a,P_b)]
\]

and

\[
\Lambda[(P_c,P_d)].
\]

Let the signed output symbols represented by these reduced pairs be

\[
b
\]

and

\[
c,
\]

respectively. Thus,

\[
\Lambda[(P_a,P_b)]\equiv b
\]

and

\[
\Lambda[(P_c,P_d)]\equiv c.
\]

The multiplication function for the two signed-pair inputs will be defined after multiplication of the signed symbols \(b\) and \(c\) has been constructed below.

\subsection*{1. Absolute-Value Function}

We first define a function

\[
\operatorname{abs}
\]

on signed output symbols.

For any signed output symbol \(\delta\), define

\[
\boxed{
\operatorname{abs}(\delta)
=
\begin{cases}
\delta,
&
\delta\text{ is nonnegative},
\\[6pt]
\text{the corresponding nonnegative symbol obtained by removing the sign }-,
&
\delta\text{ is negative}.
\end{cases}
}
\]

Thus,

\[
\operatorname{abs}(0)=0,
\]

\[
\operatorname{abs}(1)=1,
\]

\[
\operatorname{abs}(2)=2,
\]

and

\[
\operatorname{abs}(-1)=1,
\]

\[
\operatorname{abs}(-2)=2,
\]

and so on.

Hence

\[
\operatorname{abs}(\delta)
\]

always produces a nonnegative natural-number symbol.

\subsection*{2. Repeated Blocks of Successor Applications}

We now introduce the notation

\[
\Sigma^u_v(P)
\]

for nonnegative natural-number symbols

\[
u,v\in\mathbb N.
\]

The expression

\[
\Sigma^u_v(P)
\]

means:

\begin{quote}
apply \(\Sigma\) to the input \(P\) exactly \(u\) times per block, and repeat that block exactly \(v\) times.
\end{quote}

This notation is defined recursively and therefore does not assume multiplication.

For every canonical set \(P\), define the base case

\[
\boxed{
\Sigma^u_0(P)=P.
}
\]

Thus zero blocks of \(u\) successor applications leave the input unchanged.

For the recursive step, suppose

\[
\Sigma^u_v(P)
\]

has already been constructed.

Then define

\[
\boxed{
\Sigma^u_{v+1}(P)
=
\Sigma^u
\left(
\Sigma^u_v(P)
\right).
}
\]

Here

\[
\Sigma^u(Q)
\]

means the already-defined operation of applying \(\Sigma\) to \(Q\) exactly \(u\) times.

Therefore each increase of the lower index by one applies one additional block of \(u\) successor operations.

For example,

\[
\Sigma^3_0(P_0)=P_0.
\]

Then

\[
\Sigma^3_1(P_0)
=
\Sigma^3(P_0),
\]

and

\[
\Sigma^3_2(P_0)
=
\Sigma^3
\left(
\Sigma^3_1(P_0)
\right).
\]

Substituting the definition of \(\Sigma^3_1(P_0)\),

\[
\Sigma^3_2(P_0)
=
\Sigma^3
\left(
\Sigma^3(P_0)
\right).
\]

Expanding the first block,

\[
\Sigma^3(P_0)
=
\Sigma(\Sigma(\Sigma(P_0))).
\]

Therefore,

\[
\Sigma^3_2(P_0)
=
\Sigma^3
\left(
\Sigma(\Sigma(\Sigma(P_0)))
\right).
\]

Expanding the second block gives

\[
\Sigma^3_2(P_0)
=
\Sigma(\Sigma(\Sigma(\Sigma(\Sigma(\Sigma(P_0)))))).
\]

Hence

\[
\Theta\left(\Sigma^3_2(P_0)\right)=6.
\]

The value \(6\) is therefore produced from repeated successor operations alone, without assuming multiplication beforehand.

More generally,

\[
\Sigma^u_v(P_0)
\]

constructs the canonical set obtained by applying \(\Sigma\) in \(v\) consecutive blocks, each containing exactly \(u\) applications.

\subsection*{3. Unsigned Multiplication}

Let

\[
b,c
\]

be the signed output symbols obtained from

\[
\Lambda[(P_a,P_b)]
\]

and

\[
\Lambda[(P_c,P_d)].
\]

Since

\[
\operatorname{abs}(b)
\]

and

\[
\operatorname{abs}(c)
\]

are both nonnegative natural-number symbols, the expression

\[
\Sigma^{\operatorname{abs}(b)}_{\operatorname{abs}(c)}(P_0)
\]

is well-defined.

We define the unsigned magnitude of the multiplication result by

\[
\boxed{
M(b,c)
=
\Theta\left(
\Sigma^{\operatorname{abs}(b)}_{\operatorname{abs}(c)}
(P_0)
\right).
}
\]

Thus \(M(b,c)\) is always a nonnegative natural-number symbol.

For example, if

\[
b=3
\]

and

\[
c=2,
\]

then

\[
M(3,2)
=
\Theta\left(
\Sigma^3_2(P_0)
\right).
\]

From the recursive construction above,

\[
\Sigma^3_2(P_0)
=
\Sigma(\Sigma(\Sigma(\Sigma(\Sigma(\Sigma(P_0)))))),
\]

so

\[
M(3,2)=6.
\]

Likewise, if

\[
b=-3
\]

and

\[
c=2,
\]

then

\[
\operatorname{abs}(-3)=3
\]

and

\[
\operatorname{abs}(2)=2,
\]

so the unsigned magnitude is still

\[
M(-3,2)
=
\Theta\left(
\Sigma^3_2(P_0)
\right)
=
6.
\]

The sign of the final multiplication result is determined separately.

\subsection*{4. Sign of the Multiplication Result}

The sign of the result depends on the signs of

\[
b
\]

and

\[
c.
\]

If either input is zero, define

\[
\boxed{
\Upsilon(b,c)=0
}
\]

whenever

\[
b=0
\]

or

\[
c=0.
\]

If \(b\) and \(c\) are both positive, the result is nonnegative:

\[
\boxed{
\Upsilon(b,c)
=
M(b,c).
}
\]

If \(b\) and \(c\) are both negative, the result is also nonnegative:

\[
\boxed{
\Upsilon(b,c)
=
M(b,c).
}
\]

If exactly one of \(b\) and \(c\) is negative, the result is the corresponding negative output symbol:

\[
\boxed{
\Upsilon(b,c)
=
-M(b,c).
}
\]

Therefore,

\[
\boxed{
\Upsilon(b,c)
=
\begin{cases}
0,
&
b=0\text{ or }c=0,
\\[6pt]
M(b,c),
&
b,c\text{ have the same sign},
\\[6pt]
-M(b,c),
&
b,c\text{ have different signs}.
\end{cases}
}
\]

Substituting the definition of \(M(b,c)\),

\[
\boxed{
\Upsilon(b,c)
=
\begin{cases}
0,
&
b=0\text{ or }c=0,
\\[8pt]
\Theta\left(
\Sigma^{\operatorname{abs}(b)}_{\operatorname{abs}(c)}
(P_0)
\right),
&
b,c\text{ have the same sign},
\\[10pt]
-
\Theta\left(
\Sigma^{\operatorname{abs}(b)}_{\operatorname{abs}(c)}
(P_0)
\right),
&
b,c\text{ have different signs}.
\end{cases}
}
\]

Once \(\Upsilon(b,c)\) has been defined, we introduce the ordinary multiplication notation

\[
\boxed{
b\cdot c:=\Upsilon(b,c).
}
\]

This notation does not introduce a new operation; it is only a shorter name for the multiplication function already constructed.

\subsection*{5. Multiplication of Signed-Pair Representations}

Returning to the original signed-pair inputs,

\[
(P_a,P_b)
\]

and

\[
(P_c,P_d),
\]

let

\[
\Lambda[(P_a,P_b)]\equiv b
\]

and

\[
\Lambda[(P_c,P_d)]\equiv c.
\]

Then define

\[
\boxed{
\Upsilon
\left[
(P_a,P_b),(P_c,P_d)
\right]
=
\Upsilon(b,c).
}
\]

Equivalently, reduce both input pairs first, identify the signed symbols represented by those reduced pairs as \(b\) and \(c\), and then evaluate \(\Upsilon(b,c)\). The reduction function itself still returns a reduced ordered pair; the symbols \(b\) and \(c\) are the signed notations assigned to those reduced pairs.

Expanding the definition completely,

\[
\boxed{
\Upsilon
\left[
(P_a,P_b),(P_c,P_d)
\right]
=
\begin{cases}
0,
&
b=0\text{ or }c=0,
\\[8pt]
\Theta\left(
\Sigma^{\operatorname{abs}(b)}_{\operatorname{abs}(c)}
(P_0)
\right),
&
b,c\text{ have the same sign},
\\[10pt]
-
\Theta\left(
\Sigma^{\operatorname{abs}(b)}_{\operatorname{abs}(c)}
(P_0)
\right),
&
b,c\text{ have different signs},
\end{cases}
}
\]

where

\[
\Lambda[(P_a,P_b)]\equiv b
\]

and

\[
\Lambda[(P_c,P_d)]\equiv c.
\]

Thus multiplication is constructed entirely from the previously defined operations

\[
P_0,
\qquad
\Sigma,
\qquad
\Theta,
\qquad
\Lambda,
\]

together with the recursively defined repeated-block notation

\[
\Sigma^u_v(P),
\]

which is instantiated in multiplication with

\[
u=\operatorname{abs}(b),
\qquad
v=\operatorname{abs}(c).
\]

\section*{Euclidean Division and Modular Remainders}

We now define a division-and-remainder procedure using the previously constructed signed integers, absolute value, successor operation, and deterministic element removal.

Let

\[
(P_a,P_b)
\]

and

\[
(P_c,P_d)
\]

be signed-pair representations.

Reduce both pairs and let the signed symbols represented by the reduced pairs be

\[
b
\]

and

\[
c,
\]

respectively. Thus

\[
\Lambda[(P_a,P_b)]\equiv b
\]

and

\[
\Lambda[(P_c,P_d)]\equiv c.
\]

The divisor must be nonzero, so throughout this section assume

\[
\boxed{c\neq0.}
\]

As in the multiplication section, \(b\) and \(c\) here denote signed output symbols represented by reduced pairs.

\subsection*{1. Magnitude Sets}

Construct the canonical set representing the magnitude of the dividend:

\[
Q_0
=
\Sigma^{\operatorname{abs}(b)}(P_0).
\]

Construct the canonical set representing the magnitude of the divisor:

\[
C
=
\Sigma^{\operatorname{abs}(c)}(P_0).
\]

Therefore

\[
\Theta(Q_0)=\operatorname{abs}(b)
\]

and

\[
\Theta(C)=\operatorname{abs}(c).
\]

Also initialize an empty output-count set

\[
O_0=P_0.
\]

The set \(Q_n\) will record the amount still remaining after \(n\) complete divisor-sized removals, while \(O_n\) will record how many complete removals have occurred.

\subsection*{2. Full-Block Removal Rule}

A divisor-sized block may be removed only in full. No partial block is permitted.

Suppose \(Q_n\) and \(O_n\) have already been constructed. If

\[
\Theta(C)\leq\Theta(Q_n),
\]

then define

\[
\boxed{
Q_{n+1}
=
\Nu^{\Theta(C)}(Q_n)
}
\]

and simultaneously define

\[
\boxed{
O_{n+1}=\Sigma(O_n).
}
\]

Thus one complete block containing exactly \(\Theta(C)\) elements is removed from \(Q_n\), and exactly one successor is applied to the count set \(O_n\).

Whenever such a full block is permitted, the previously defined natural-subtraction function records the same numerical step:

\[
\Delta(Q_n,C)
=
\Theta\left(\Nu^{\Theta(C)}(Q_n)\right)
=
\Theta(Q_{n+1}).
\]

If instead

\[
\Theta(Q_n)<\Theta(C),
\]

then no removal is performed and the process stops.

This rule implements the intended repeated natural subtraction without creating a type inconsistency. The previously defined function \(\Delta(P_1,P_2)\) returns an output symbol, not a set, so it cannot itself be iterated as a set transformation. The actual repeated removal underlying \(\Delta\) is therefore written using \(\Nu^{\Theta(C)}\).

Because each successful step removes at least one element from the finite set \(Q_n\), and because \(c\neq0\) implies \(\Theta(C)>0\), the process terminates after finitely many steps.

Let \(m\) be the first stage at which

\[
\Theta(Q_m)<\Theta(C).
\]

Define the unsigned quotient magnitude

\[
\boxed{
q_0:=\Theta(O_m)
}
\]

and the unsigned leftover magnitude

\[
\boxed{
r_0:=\Theta(Q_m).
}
\]

By construction,

\[
0\leq r_0<\operatorname{abs}(c).
\]

For example, if

\[
b=17,
\qquad
c=5,
\]

then the successive magnitudes of \(Q_n\) are

\[
17,\ 12,\ 7,\ 2.
\]

Three complete blocks are removed, so

\[
q_0=3,
\qquad
r_0=2.
\]

\subsection*{3. Signed Euclidean Quotient and Remainder}

The unsigned process above divides \(\operatorname{abs}(b)\) by \(\operatorname{abs}(c)\).

We now assign signs so that the final quotient \(q\) and remainder \(r\) always satisfy

\[
\boxed{
b=q\cdot c+r
}
\]

and

\[
\boxed{
0\leq r<\operatorname{abs}(c).
}
\]

If \(b\) is nonnegative, define

\[
r=r_0,
\]

and define

\[
q=
\begin{cases}
q_0, & c>0,\\[4pt]
-q_0, & c<0.
\end{cases}
\]

If \(b\) is negative and \(r_0=0\), define

\[
r=0,
\]

and

\[
q=
\begin{cases}
-q_0, & c>0,\\[4pt]
q_0, & c<0.
\end{cases}
\]

Finally, if \(b\) is negative and \(r_0>0\), one additional divisor-sized block is required in the signed quotient so that the remainder remains nonnegative.

Define

\[
\boxed{
r=\operatorname{abs}(c)-r_0
}
\]

and

\[
\boxed{
q=
\begin{cases}
-(q_0+1), & c>0,\\[4pt]
q_0+1, & c<0.
\end{cases}
}
\]

This adjustment is necessary because simply attaching a negative sign to \(q_0\) would produce a negative remainder when the dividend is negative and \(r_0\neq0\).

\subsection*{4. Definition of \(\Xi\)}

Define

\[
\boxed{
\Xi
\left[
(P_a,P_b),(P_c,P_d)
\right]
=
\Xi(b,c)
=
(q,r),
}
\]

where \(b\) and \(c\) are the signed symbols represented by

\[
\Lambda[(P_a,P_b)]
\]

and

\[
\Lambda[(P_c,P_d)],
\]

and where \(q\) and \(r\) are constructed by the full-block removal and sign rules above.

Thus \(\Xi\) returns two output symbols:

\[
\boxed{
\text{quotient }q
\qquad\text{and}\qquad
\text{remainder }r.
}
\]

The output always satisfies

\[
\boxed{
b=q\cdot c+r,
\qquad
0\leq r<\operatorname{abs}(c).
}
\]

\subsection*{5. Examples}

For \(b=17\) and \(c=5\),

\[
\Xi(17,5)=(3,2),
\]

because

\[
17=3\cdot5+2.
\]

For \(b=-17\) and \(c=5\), the unsigned process still gives

\[
q_0=3,
\qquad
r_0=2.
\]

Since the dividend is negative and \(r_0>0\),

\[
q=-(3+1)=-4
\]

and

\[
r=5-2=3.
\]

Hence

\[
\Xi(-17,5)=(-4,3),
\]

and indeed

\[
-17=(-4)\cdot5+3.
\]

For \(b=17\) and \(c=-5\),

\[
\Xi(17,-5)=(-3,2),
\]

because

\[
17=(-3)\cdot(-5)+2.
\]

For \(b=-17\) and \(c=-5\),

\[
\Xi(-17,-5)=(4,3),
\]

because

\[
-17=4\cdot(-5)+3.
\]

\subsection*{6. Modulo}

For modular arithmetic, the modulus is taken to be a positive natural-number symbol \(m\).

If

\[
\Xi(b,m)=(q,r),
\]

then define

\[
\boxed{
b\bmod m:=r.
}
\]

Thus the modulo operation returns the nonnegative remainder produced by \(\Xi\), and it always satisfies

\[
\boxed{
0\leq b\bmod m<m.
}
\]

For example,

\[
17\bmod5=2
\]

and

\[
-17\bmod5=3.
\]

Two signed integers \(x\) and \(y\) are said to be congruent modulo \(m\) when they produce the same remainder under this operation.

We write

\[
\boxed{
x\equiv y\pmod m
}
\]

precisely when

\[
x\bmod m=y\bmod m.
\]

For example,

\[
17\equiv2\pmod5
\]

and

\[
-17\equiv3\pmod5.
\]

\section*{Defining Quotient and Remainder Output Functions}

Recall that for signed integers \(b\) and \(c\neq 0\),

\[
\Xi(b,c)=(q,r),
\]

where

\[
b=q\cdot c+r
\]

and

\[
0\leq r<\operatorname{abs}(c).
\]

We now define two functions that extract the two outputs of \(\Xi\).

\subsection*{1. Quotient Output Function}

If

\[
\Xi(b,c)=(q,r),
\]

define

\[
\boxed{
\operatorname{quo}(\Xi(b,c)):=q.
}
\]

Therefore,

\[
\operatorname{quo}
\left(
\Xi(b,c)
\right)
\]

returns only the quotient produced by \(\Xi\).

For signed-pair inputs,

\[
\boxed{
\operatorname{quo}
\left(
\Xi[(P_a,P_b),(P_c,P_d)]
\right)
:=
q
}
\]

whenever

\[
\Xi[(P_a,P_b),(P_c,P_d)]
=
(q,r).
\]

\subsection*{2. Remainder Output Function}

If

\[
\Xi(b,c)=(q,r),
\]

define

\[
\boxed{
\operatorname{rem}(\Xi(b,c)):=r.
}
\]

Therefore,

\[
\operatorname{rem}
\left(
\Xi(b,c)
\right)
\]

returns only the remainder produced by \(\Xi\).

For signed-pair inputs,

\[
\boxed{
\operatorname{rem}
\left(
\Xi[(P_a,P_b),(P_c,P_d)]
\right)
:=
r
}
\]

whenever

\[
\Xi[(P_a,P_b),(P_c,P_d)]
=
(q,r).
\]

Because \(\Xi\) is defined so that

\[
0\leq r<\operatorname{abs}(c),
\]

the remainder function always satisfies

\[
\boxed{
0
\leq
\operatorname{rem}(\Xi(b,c))
<
\operatorname{abs}(c).
}
\]

When the divisor is a positive modulus \(v\),

\[
c=v>0,
\]

this becomes

\[
\boxed{
0
\leq
\operatorname{rem}(\Xi(b,v))
<
v.
}
\]

\section*{Defining Vectors over \(\mathbb Z_v\)}

We now define finite vectors whose coordinates are signed integers reduced modulo a common positive modulus \(v\).

Let

\[
u\in\mathbb N
\]

be the number of coordinates in the vector, and let

\[
v\in\mathbb N
\]

with

\[
v>0.
\]

A vector containing exactly \(u\) coordinates modulo \(v\) is written

\[
\boxed{
\vec{x}\in\mathbb Z_v^u.
}
\]

Here,

\[
u
\]

specifies the number of coordinates, while

\[
v
\]

specifies the modulus used for every coordinate.

\subsection*{1. Construction of a Coordinate}

Each coordinate is constructed from two signed-pair representations.

Let

\[
(P_a,P_b)
\]

be any signed-pair representation.

Its reduced signed value may be any integer:

\[
\Lambda[(P_a,P_b)]\equiv s.
\]

Let

\[
(P_c,P_d)
\]

be a signed-pair representation satisfying

\[
\boxed{
\Lambda[(P_c,P_d)]\equiv v,
}
\]

where

\[
v>0.
\]

Then

\[
\Xi[(P_a,P_b),(P_c,P_d)]
\]

produces a quotient and remainder.

The coordinate stored in the vector is defined to be only the remainder:

\[
\boxed{
x_1
=
\operatorname{rem}
\left(
\Xi[(P_a,P_b),(P_c,P_d)]
\right).
}
\]

Therefore

\[
0\leq x_1<v.
\]

The first signed pair may represent any signed integer, while the second signed pair represents the fixed positive modulus \(v\).

\subsection*{2. Construction of the Vector}

Let there be exactly \(u\) signed-pair inputs

\[
(P_{a_1},P_{b_1}),
(P_{a_2},P_{b_2}),
\ldots,
(P_{a_u},P_{b_u}),
\]

and exactly \(u\) modulus-pair inputs

\[
(P_{c_1},P_{d_1}),
(P_{c_2},P_{d_2}),
\ldots,
(P_{c_u},P_{d_u}),
\]

where every modulus pair represents the same positive signed value \(v\):

\[
\boxed{
\Lambda[(P_{c_i},P_{d_i})]\equiv v
}
\]

for every

\[
i=1,2,\ldots,u.
\]

Define each coordinate by

\[
\boxed{
x_i
=
\operatorname{rem}
\left(
\Xi[
(P_{a_i},P_{b_i}),
(P_{c_i},P_{d_i})
]
\right).
}
\]

Then define the vector

\[
\boxed{
\vec{x}
=
(x_1,x_2,\ldots,x_u).
}
\]

Substituting the definitions of the coordinates,

\[
\boxed{
\vec{x}
=
\left(
\operatorname{rem}
\left(
\Xi[
(P_{a_1},P_{b_1}),
(P_{c_1},P_{d_1})
]
\right),
\operatorname{rem}
\left(
\Xi[
(P_{a_2},P_{b_2}),
(P_{c_2},P_{d_2})
]
\right),
\ldots,
\operatorname{rem}
\left(
\Xi[
(P_{a_u},P_{b_u}),
(P_{c_u},P_{d_u})
]
\right)
\right).
}
\]

Since every coordinate satisfies

\[
0\leq x_i<v,
\]

the resulting vector satisfies

\[
\boxed{
\vec{x}\in\mathbb Z_v^u.
}
\]

\subsection*{3. Expanded Three-Coordinate Example}

For a vector with

\[
u=3,
\]

write

\[
\vec{x}\in\mathbb Z_v^3.
\]

Let

\[
(P_a,P_b),
\qquad
(P_e,P_f),
\qquad
(P_i,P_j)
\]

be three arbitrary signed-pair representations.

Let

\[
(P_c,P_d),
\qquad
(P_g,P_h),
\qquad
(P_k,P_l)
\]

all represent the same positive modulus \(v\):

\[
\Lambda[(P_c,P_d)]\equiv v,
\]

\[
\Lambda[(P_g,P_h)]\equiv v,
\]

and

\[
\Lambda[(P_k,P_l)]\equiv v.
\]

Then define

\[
\boxed{
\vec{x}
=
\left(
\operatorname{rem}
\left(
\Xi[(P_a,P_b),(P_c,P_d)]
\right),
\operatorname{rem}
\left(
\Xi[(P_e,P_f),(P_g,P_h)]
\right),
\operatorname{rem}
\left(
\Xi[(P_i,P_j),(P_k,P_l)]
\right)
\right).
}
\]

Each first ordered pair may represent any signed integer.

Each second ordered pair must represent the same positive modulus \(v\).

Therefore each coordinate lies in

\[
\{0,1,2,\ldots,v-1\},
\]

and the complete vector contains exactly three coordinates.

Hence

\[
\boxed{
\vec{x}\in\mathbb Z_v^3.
}
\]

\subsection*{4. General Form}

More generally,

\[
\boxed{
\vec{x}\in\mathbb Z_v^u
}
\]

means that

\[
\vec{x}
=
(x_1,x_2,\ldots,x_u)
\]

contains exactly \(u\) coordinates and every coordinate satisfies

\[
\boxed{
0\leq x_i<v.
}
\]

Within the present system, each coordinate is obtained from

\[
\boxed{
x_i
=
\operatorname{rem}
\left(
\Xi[
(P_{a_i},P_{b_i}),
(P_{c_i},P_{d_i})
]
\right),
}
\]

with

\[
\boxed{
\Lambda[(P_{c_i},P_{d_i})]\equiv v
}
\]

for every coordinate.

Thus the first signed-pair input may vary independently from coordinate to coordinate, while every second signed-pair input represents the same positive modulus \(v\).

\section*{Matrix-Vector Multiplication with Signed-Pair Outputs}

We now define a matrix, a vector, a canonical symbol-to-pair map, and the corresponding matrix-vector product.

\subsection*{1. Matrix Definition}

Let

\[
A
=
\begin{pmatrix}
(P_{a_1},P_{b_1}) & (P_{c_1},P_{d_1})\\
(P_{a_2},P_{b_2}) & (P_{c_2},P_{d_2})
\end{pmatrix}.
\]

Each matrix entry is a signed-pair representation.

Thus the four entries represent signed integers through reduction by \(\Lambda\):

\[
\Lambda[(P_{a_1},P_{b_1})],
\qquad
\Lambda[(P_{c_1},P_{d_1})],
\]

\[
\Lambda[(P_{a_2},P_{b_2})],
\qquad
\Lambda[(P_{c_2},P_{d_2})].
\]

No requirement is made that the matrix entries already be reduced.

\subsection*{2. Vector Definition}

Let

\[
\vec{x}
=
\begin{pmatrix}
x_1\\
x_2
\end{pmatrix}.
\]

The coordinates

\[
x_1
\qquad\text{and}\qquad
x_2
\]

are signed numerical symbols.

Unlike the entries of \(A\), the coordinates of \(\vec{x}\) are not themselves ordered pairs of canonical sets.

Therefore, before a vector coordinate can be used as an input to \(\Upsilon\), it must be converted into a signed-pair representation.

\subsection*{3. Definition of \(\Lambda^{-1}\)}

Define the canonical symbol-to-pair function

\[
\Lambda^{-1}
\]

on signed numerical symbols.

For any signed symbol \(s\), define

\[
\boxed{
\Lambda^{-1}(s)
=
\begin{cases}
(P_{\operatorname{abs}(s)},P_0),
&
s>0,
\\[6pt]
(P_0,P_{\operatorname{abs}(s)}),
&
s<0,
\\[6pt]
(P_0,P_0),
&
s=0.
\end{cases}
}
\]

Equivalently, using the successor construction,

\[
\boxed{
\Lambda^{-1}(s)
=
\begin{cases}
\left(
\Sigma^{\operatorname{abs}(s)}(P_0),
P_0
\right),
&
s>0,
\\[8pt]
\left(
P_0,
\Sigma^{\operatorname{abs}(s)}(P_0)
\right),
&
s<0,
\\[8pt]
(P_0,P_0),
&
s=0.
\end{cases}
}
\]

Thus, for example,

\[
\Lambda^{-1}(3)=(P_3,P_0),
\]

\[
\Lambda^{-1}(-3)=(P_0,P_3),
\]

and

\[
\Lambda^{-1}(0)=(P_0,P_0).
\]

\subsection*{4. Why \(\Lambda^{-1}\) Is Not a True Inverse}

The notation

\[
\Lambda^{-1}
\]

is retained by definition, but it is not a true inverse function in the ordinary set-theoretic sense.

The reason is that infinitely many different unreduced signed pairs may represent the same signed numerical symbol.

For example,

\[
(P_3,P_0),
\]

\[
(P_4,P_1),
\]

\[
(P_5,P_2),
\]

and, more generally,

\[
(P_{3+v},P_v)
\]

for arbitrary

\[
v\in\mathbb N
\]

all reduce to the same signed value.

Therefore, given only the symbol

\[
3,
\]

there is no unique original ordered pair that can be recovered.

The function

\[
\Lambda^{-1}
\]

does not attempt to recover the original unreduced representation.

Instead, it returns the unique canonical reduced pair corresponding to the signed symbol.

Hence,

\[
\boxed{
\Lambda^{-1}(3)=(P_3,P_0)
}
\]

even if the value \(3\) originally arose from

\[
(P_8,P_5).
\]

The function therefore satisfies the canonical recovery property

\[
\boxed{
\Lambda[\Lambda^{-1}(s)]\equiv s.
}
\]

However, in general,

\[
\boxed{
\Lambda^{-1}
\left(
\Lambda[(P_a,P_b)]
\right)
\neq
(P_a,P_b)
}
\]

whenever the original pair is unreduced.

Instead,

\[
\Lambda^{-1}
\left(
\Lambda[(P_a,P_b)]
\right)
\]

returns the canonical reduced pair representing the same signed value.

\subsection*{5. Unreduced Matrix-Entry--Vector-Coordinate Multiplication}

Since \(\Upsilon\) accepts signed-pair inputs, a vector coordinate must first be converted using \(\Lambda^{-1}\).

For the matrix entry

\[
(P_{a_1},P_{b_1})
\]

and vector coordinate

\[
x_1,
\]

the product is

\[
\Upsilon
\left[
(P_{a_1},P_{b_1}),
\Lambda^{-1}(x_1)
\right].
\]

The output of \(\Upsilon\) is a signed numerical symbol.

Since \(\Gamma\) requires signed-pair inputs, whenever this product is to be used as an input to \(\Gamma\), the output of \(\Upsilon\) must be converted back into a signed pair using \(\Lambda^{-1}\).

Thus the corresponding signed-pair product is

\[
\boxed{
\Lambda^{-1}
\left(
\Upsilon
\left[
(P_{a_1},P_{b_1}),
\Lambda^{-1}(x_1)
\right]
\right).
}
\]

Likewise,

\[
\boxed{
\Lambda^{-1}
\left(
\Upsilon
\left[
(P_{c_1},P_{d_1}),
\Lambda^{-1}(x_2)
\right]
\right).
}
\]

\subsection*{6. Overbar Notation for Pre-Modular Results}

From this point onward, an overbar placed over a vector expression denotes that the indicated arithmetic operation has been performed, but coordinate-wise modular reduction by

\[
\operatorname{rem}(\Xi(\cdot))
\]

has not yet been applied.

Thus,

\[
\boxed{
\overline{\delta\vec{x}},
\qquad
\overline{\vec{x}+\vec{y}},
\qquad
\overline{A\vec{x}}
}
\]

denote pre-modular results.

The overbar does not specify whether the coordinates are signed numerical symbols or signed pairs. Their type is determined by the function producing them.

In particular:

\[
\Upsilon
\]

produces signed numerical symbols, while

\[
\Gamma
\]

produces reduced signed pairs.

The overbar indicates only that the final modular-remainder step has not yet been applied.

\subsection*{7. Matrix-Vector Multiplication Before Modular Reduction}

Let

\[
A
=
\begin{pmatrix}
(P_{a_1},P_{b_1}) & (P_{c_1},P_{d_1})\\
(P_{a_2},P_{b_2}) & (P_{c_2},P_{d_2})
\end{pmatrix}
\]

and

\[
\vec{x}
=
\begin{pmatrix}
x_1\\
x_2
\end{pmatrix}.
\]

The first coordinate of the pre-modular matrix-vector product

\[
\overline{A\vec{x}}
\]

is obtained by multiplying each entry of the first row by the corresponding vector coordinate and then combining the resulting signed-pair products using \(\Gamma\).

Define

\[
\boxed{
\overline{y}_1
=
\Gamma
\left(
\Lambda^{-1}
\left(
\Upsilon
\left[
(P_{a_1},P_{b_1}),
\Lambda^{-1}(x_1)
\right]
\right),
\Lambda^{-1}
\left(
\Upsilon
\left[
(P_{c_1},P_{d_1}),
\Lambda^{-1}(x_2)
\right]
\right)
\right).
}
\]

Similarly,

\[
\boxed{
\overline{y}_2
=
\Gamma
\left(
\Lambda^{-1}
\left(
\Upsilon
\left[
(P_{a_2},P_{b_2}),
\Lambda^{-1}(x_1)
\right]
\right),
\Lambda^{-1}
\left(
\Upsilon
\left[
(P_{c_2},P_{d_2}),
\Lambda^{-1}(x_2)
\right]
\right)
\right).
}
\]

Therefore define

\[
\boxed{
\overline{A\vec{x}}
=
\begin{pmatrix}
\overline{y}_1\\
\overline{y}_2
\end{pmatrix}.
}
\]

Substituting the definitions directly,

\[
\boxed{
\overline{A\vec{x}}
=
\begin{pmatrix}
\Gamma
\left(
\Lambda^{-1}
\left(
\Upsilon
\left[
(P_{a_1},P_{b_1}),
\Lambda^{-1}(x_1)
\right]
\right),
\Lambda^{-1}
\left(
\Upsilon
\left[
(P_{c_1},P_{d_1}),
\Lambda^{-1}(x_2)
\right]
\right)
\right)
\\[18pt]
\Gamma
\left(
\Lambda^{-1}
\left(
\Upsilon
\left[
(P_{a_2},P_{b_2}),
\Lambda^{-1}(x_1)
\right]
\right),
\Lambda^{-1}
\left(
\Upsilon
\left[
(P_{c_2},P_{d_2}),
\Lambda^{-1}(x_2)
\right]
\right)
\right)
\end{pmatrix}.
}
\]

Each coordinate of

\[
\overline{A\vec{x}}
\]

is therefore a reduced signed-pair output produced by \(\Gamma\).

At this stage,

\[
\operatorname{rem}(\Xi(\cdot))
\]

has not been applied.

Thus

\[
\overline{A\vec{x}}
\]

denotes the ordinary signed matrix-vector product before reduction modulo a chosen modulus.

The type flow of each individual multiplication term is

\[
\boxed{
\text{symbol}
\overset{\Lambda^{-1}}{\longrightarrow}
\text{signed pair}
\overset{\Upsilon}{\longrightarrow}
\text{signed symbol}
\overset{\Lambda^{-1}}{\longrightarrow}
\text{signed pair}.
}
\]

The resulting signed-pair products are then combined using \(\Gamma\).

\section*{Vector Operations}

Let

\[
\vec{x}
=
\begin{pmatrix}
x_1\\
x_2\\
\vdots\\
x_u
\end{pmatrix}
\]

and

\[
\vec{y}
=
\begin{pmatrix}
y_1\\
y_2\\
\vdots\\
y_u
\end{pmatrix}
\]

be vectors of equal dimension \(u\).

When modular vector arithmetic is considered, assume

\[
\vec{x},\vec{y}\in\mathbb Z_v^u,
\]

where \(v>0\).

Let the signed-pair representation of the common modulus \(v\) used for coordinate \(i\) be

\[
(P_{a_i},P_{b_i}),
\]

with

\[
\boxed{
\Lambda[(P_{a_i},P_{b_i})]\equiv v.
}
\]

\subsection*{1. Vector Addition Before Modular Reduction}

Since each coordinate \(x_i\) and \(y_i\) is a numerical symbol, both must first be converted into signed-pair form before being supplied to \(\Gamma\).

For each coordinate \(i\), define the pre-modular sum

\[
\boxed{
\overline{z}_i
=
\Gamma
\left(
\Lambda^{-1}(x_i),
\Lambda^{-1}(y_i)
\right).
}
\]

Therefore,

\[
\boxed{
\overline{\vec{x}+\vec{y}}
=
\begin{pmatrix}
\Gamma
\left(
\Lambda^{-1}(x_1),
\Lambda^{-1}(y_1)
\right)
\\[8pt]
\Gamma
\left(
\Lambda^{-1}(x_2),
\Lambda^{-1}(y_2)
\right)
\\
\vdots
\\
\Gamma
\left(
\Lambda^{-1}(x_u),
\Lambda^{-1}(y_u)
\right)
\end{pmatrix}.
}
\]

Each coordinate of

\[
\overline{\vec{x}+\vec{y}}
\]

is a reduced signed pair produced by \(\Gamma\).

No modular reduction has yet been applied.

\subsection*{2. Vector Addition Modulo \(v\)}

To return each coordinate to \(\mathbb Z_v\), apply \(\Xi\) using the corresponding modulus pair and extract the remainder.

Thus,

\[
\boxed{
\vec{x}+\vec{y}
=
\begin{pmatrix}
\operatorname{rem}
\left(
\Xi
\left[
\Gamma
\left(
\Lambda^{-1}(x_1),
\Lambda^{-1}(y_1)
\right),
(P_{a_1},P_{b_1})
\right]
\right)
\\[12pt]
\operatorname{rem}
\left(
\Xi
\left[
\Gamma
\left(
\Lambda^{-1}(x_2),
\Lambda^{-1}(y_2)
\right),
(P_{a_2},P_{b_2})
\right]
\right)
\\
\vdots
\\
\operatorname{rem}
\left(
\Xi
\left[
\Gamma
\left(
\Lambda^{-1}(x_u),
\Lambda^{-1}(y_u)
\right),
(P_{a_u},P_{b_u})
\right]
\right)
\end{pmatrix}.
}
\]

Therefore,

\[
\boxed{
\vec{x}+\vec{y}\in\mathbb Z_v^u.
}
\]

The distinction is

\[
\boxed{
\overline{\vec{x}+\vec{y}}
=
\text{coordinate-wise signed addition before modulo}
}
\]

while

\[
\boxed{
\vec{x}+\vec{y}
=
\text{coordinate-wise signed addition after modulo }v.
}
\]

\subsection*{3. Scalar-Vector Multiplication Before Modular Reduction}

Let

\[
\delta
\]

be a signed numerical symbol.

Since \(\Upsilon\) requires signed-pair inputs, convert both the scalar and each vector coordinate using \(\Lambda^{-1}\).

For each coordinate \(x_i\), define

\[
\boxed{
\overline{w}_i
=
\Upsilon
\left[
\Lambda^{-1}(\delta),
\Lambda^{-1}(x_i)
\right].
}
\]

Because \(\Upsilon\) returns a signed numerical symbol, each coordinate of the pre-modular scalar-vector product is a signed symbol.

Therefore,

\[
\boxed{
\overline{\delta\vec{x}}
=
\begin{pmatrix}
\Upsilon
\left[
\Lambda^{-1}(\delta),
\Lambda^{-1}(x_1)
\right]
\\[8pt]
\Upsilon
\left[
\Lambda^{-1}(\delta),
\Lambda^{-1}(x_2)
\right]
\\
\vdots
\\
\Upsilon
\left[
\Lambda^{-1}(\delta),
\Lambda^{-1}(x_u)
\right]
\end{pmatrix}.
}
\]

At this stage no modular reduction has been applied.

Thus,

\[
\boxed{
\overline{\delta\vec{x}}
=
\text{scalar-vector multiplication before modulo }v.
}
\]

\subsection*{4. Scalar-Vector Multiplication Modulo \(v\)}

To apply \(\Xi\) in its signed-pair form, each signed-symbol output of \(\Upsilon\) must first be converted back into a signed pair using \(\Lambda^{-1}\).

For each coordinate,

\[
\Lambda^{-1}
\left(
\Upsilon
\left[
\Lambda^{-1}(\delta),
\Lambda^{-1}(x_i)
\right]
\right)
\]

is the canonical signed-pair representation of the pre-modular product.

Therefore define

\[
\boxed{
\delta\vec{x}
=
\begin{pmatrix}
\operatorname{rem}
\left(
\Xi
\left[
\Lambda^{-1}
\left(
\Upsilon
\left[
\Lambda^{-1}(\delta),
\Lambda^{-1}(x_1)
\right]
\right),
(P_{a_1},P_{b_1})
\right]
\right)
\\[14pt]
\operatorname{rem}
\left(
\Xi
\left[
\Lambda^{-1}
\left(
\Upsilon
\left[
\Lambda^{-1}(\delta),
\Lambda^{-1}(x_2)
\right]
\right),
(P_{a_2},P_{b_2})
\right]
\right)
\\
\vdots
\\
\operatorname{rem}
\left(
\Xi
\left[
\Lambda^{-1}
\left(
\Upsilon
\left[
\Lambda^{-1}(\delta),
\Lambda^{-1}(x_u)
\right]
\right),
(P_{a_u},P_{b_u})
\right]
\right)
\end{pmatrix}.
}
\]

Hence,

\[
\boxed{
\delta\vec{x}\in\mathbb Z_v^u.
}
\]

The distinction is therefore

\[
\boxed{
\overline{\delta\vec{x}}
=
\text{scalar multiplication before coordinate-wise modular reduction}
}
\]

and

\[
\boxed{
\delta\vec{x}
=
\text{scalar multiplication after coordinate-wise modular reduction}.
}
\]

\subsection*{5. Type Summary}

For vector addition,

\[
\boxed{
x_i
\overset{\Lambda^{-1}}{\longrightarrow}
\text{signed pair},
\qquad
y_i
\overset{\Lambda^{-1}}{\longrightarrow}
\text{signed pair},
}
\]

followed by

\[
\boxed{
\Gamma:
(\text{signed pair},\text{signed pair})
\longrightarrow
\text{signed pair}.
}
\]

Thus each coordinate of

\[
\overline{\vec{x}+\vec{y}}
\]

is a signed pair.

For scalar-vector multiplication,

\[
\boxed{
\delta
\overset{\Lambda^{-1}}{\longrightarrow}
\text{signed pair},
\qquad
x_i
\overset{\Lambda^{-1}}{\longrightarrow}
\text{signed pair},
}
\]

followed by

\[
\boxed{
\Upsilon:
(\text{signed pair},\text{signed pair})
\longrightarrow
\text{signed symbol}.
}
\]

Thus each coordinate of

\[
\overline{\delta\vec{x}}
\]

is a signed numerical symbol.

Before pair-form \(\Xi\) can be applied to such a coordinate, the coordinate is converted by

\[
\boxed{
\Lambda^{-1}:
\text{signed symbol}
\longrightarrow
\text{canonical signed pair}.
}
\]

Finally,

\[
\boxed{
\operatorname{rem}(\Xi(\cdot))
}
\]

returns the numerical coordinate reduced modulo \(v\).
\subsection*{Dot Product of Two Vectors}

Let

\[
\vec{x}
=
(x_1,x_2,\ldots,x_u)
\]

and

\[
\vec{y}
=
(y_1,y_2,\ldots,y_u)
\]

be vectors of equal dimension \(u\).

For each coordinate \(i\), first convert the numerical symbols

\[
x_i
\qquad\text{and}\qquad
y_i
\]

into canonical signed-pair representations using \(\Lambda^{-1}\).

Then multiply the corresponding coordinates using \(\Upsilon\).

Since \(\Upsilon\) returns a signed numerical symbol, convert that output back into a signed pair using \(\Lambda^{-1}\).

Define

\[
\boxed{
T_i
=
\Lambda^{-1}
\left(
\Upsilon
\left[
\Lambda^{-1}(x_i),
\Lambda^{-1}(y_i)
\right]
\right).
}
\]

Thus each \(T_i\) is the signed-pair representation of the product

\[
x_i y_i.
\]

For three coordinates,

\[
\vec{x}
=
(x_1,x_2,x_3)
\]

and

\[
\vec{y}
=
(y_1,y_2,y_3),
\]

the three coordinate products are

\[
T_1
=
\Lambda^{-1}
\left(
\Upsilon
\left[
\Lambda^{-1}(x_1),
\Lambda^{-1}(y_1)
\right]
\right),
\]

\[
T_2
=
\Lambda^{-1}
\left(
\Upsilon
\left[
\Lambda^{-1}(x_2),
\Lambda^{-1}(y_2)
\right]
\right),
\]

and

\[
T_3
=
\Lambda^{-1}
\left(
\Upsilon
\left[
\Lambda^{-1}(x_3),
\Lambda^{-1}(y_3)
\right]
\right).
\]

Since \(\Gamma\) accepts two signed-pair inputs and returns one signed-pair output, the products may be added recursively.

First,

\[
\Gamma(T_1,T_2)
\]

produces the signed-pair representation of

\[
x_1y_1+x_2y_2.
\]

That output may then be supplied directly as an input to another application of \(\Gamma\).

Therefore,

\[
\boxed{
\overline{\vec{x}\cdot\vec{y}}
=
\Gamma
\left(
\Gamma(T_1,T_2),
T_3
\right).
}
\]

Substituting the definitions of \(T_1,T_2,T_3\),

\[
\boxed{
\begin{aligned}
\overline{\vec{x}\cdot\vec{y}}
=
\Gamma
\Bigg(
&
\Gamma
\Bigg(
\Lambda^{-1}
\left(
\Upsilon
\left[
\Lambda^{-1}(x_1),
\Lambda^{-1}(y_1)
\right]
\right),
\\
&
\Lambda^{-1}
\left(
\Upsilon
\left[
\Lambda^{-1}(x_2),
\Lambda^{-1}(y_2)
\right]
\right)
\Bigg),
\\
&
\Lambda^{-1}
\left(
\Upsilon
\left[
\Lambda^{-1}(x_3),
\Lambda^{-1}(y_3)
\right]
\right)
\Bigg).
\end{aligned}
}
\]

The overbar indicates that the dot product has been computed, but modular reduction has not yet been applied.

More generally, for vectors of dimension \(u\),

\[
\vec{x}
=
(x_1,x_2,\ldots,x_u)
\]

and

\[
\vec{y}
=
(y_1,y_2,\ldots,y_u),
\]

define

\[
T_i
=
\Lambda^{-1}
\left(
\Upsilon
\left[
\Lambda^{-1}(x_i),
\Lambda^{-1}(y_i)
\right]
\right)
\]

for

\[
i=1,2,\ldots,u.
\]

Then define the pre-modular dot product by repeated application of \(\Gamma\):

\[
\boxed{
\overline{\vec{x}\cdot\vec{y}}
=
\Gamma
\left(
\cdots
\Gamma
\left(
\Gamma(T_1,T_2),
T_3
\right)
\cdots,
T_u
\right).
}
\]

Equivalently, define the partial sums recursively by

\[
D_1=T_1,
\]

and for

\[
i=2,3,\ldots,u,
\]

define

\[
\boxed{
D_i
=
\Gamma(D_{i-1},T_i).
}
\]

Then

\[
\boxed{
\overline{\vec{x}\cdot\vec{y}}
=
D_u.
}
\]

Thus

\[
\overline{\vec{x}\cdot\vec{y}}
\]

is a reduced signed-pair representation of

\[
x_1y_1+x_2y_2+\cdots+x_uy_u
\]

before modular reduction.

If

\[
\vec{x},\vec{y}\in\mathbb Z_v^u,
\]

and

\[
(P_a,P_b)
\]

is a signed-pair representation of the positive modulus \(v\), so that

\[
\Lambda[(P_a,P_b)]\equiv v,
\]

then the modular dot product is defined by

\[
\boxed{
\vec{x}\cdot\vec{y}
=
\operatorname{rem}
\left(
\Xi
\left[
\overline{\vec{x}\cdot\vec{y}},
(P_a,P_b)
\right]
\right).
}
\]

Therefore,

\[
\boxed{
\overline{\vec{x}\cdot\vec{y}}
=
\text{dot product before modular reduction}
}
\]

while

\[
\boxed{
\vec{x}\cdot\vec{y}
=
\text{dot product after reduction modulo }v.
}
\]
\subsection*{Matrix Addition}

Let

\[
A=
\begin{pmatrix}
A_{11} & A_{12} & \cdots & A_{1n}\\
A_{21} & A_{22} & \cdots & A_{2n}\\
\vdots & \vdots & \ddots & \vdots\\
A_{m1} & A_{m2} & \cdots & A_{mn}
\end{pmatrix}
\]

and

\[
B=
\begin{pmatrix}
B_{11} & B_{12} & \cdots & B_{1n}\\
B_{21} & B_{22} & \cdots & B_{2n}\\
\vdots & \vdots & \ddots & \vdots\\
B_{m1} & B_{m2} & \cdots & B_{mn}
\end{pmatrix}
\]

be two matrices of equal dimensions \(m\times n\).

Each entry is a signed-pair representation.

Thus, for every row \(i\) and column \(j\),

\[
A_{ij}=(P_{a_{ij}},P_{b_{ij}})
\]

and

\[
B_{ij}=(P_{c_{ij}},P_{d_{ij}}).
\]

Matrix addition is performed coordinate-wise.

Since \(\Gamma\) accepts two signed-pair inputs and returns one reduced signed-pair output, the pre-modular sum of the entries in position \((i,j)\) is

\[
\boxed{
\overline{C}_{ij}
=
\Gamma
\left(
A_{ij},
B_{ij}
\right).
}
\]

Equivalently,

\[
\boxed{
\overline{C}_{ij}
=
\Gamma
\left(
(P_{a_{ij}},P_{b_{ij}}),
(P_{c_{ij}},P_{d_{ij}})
\right).
}
\]

Therefore the pre-modular matrix sum is

\[
\boxed{
\overline{A+B}
=
\begin{pmatrix}
\Gamma(A_{11},B_{11}) &
\Gamma(A_{12},B_{12}) &
\cdots &
\Gamma(A_{1n},B_{1n})
\\[6pt]
\Gamma(A_{21},B_{21}) &
\Gamma(A_{22},B_{22}) &
\cdots &
\Gamma(A_{2n},B_{2n})
\\
\vdots & \vdots & \ddots & \vdots
\\
\Gamma(A_{m1},B_{m1}) &
\Gamma(A_{m2},B_{m2}) &
\cdots &
\Gamma(A_{mn},B_{mn})
\end{pmatrix}.
}
\]

Every entry of

\[
\overline{A+B}
\]

is therefore a reduced signed-pair output produced by \(\Gamma\).

At this stage, no modular reduction has been applied.

Thus,

\[
\boxed{
\overline{A+B}
=
\text{matrix addition before modular reduction}.
}
\]

If

\[
A,B\in\mathbb Z_v^{m\times n},
\]

then each matrix entry must be reduced modulo the same positive modulus \(v\).

Let

\[
(P_{p_{ij}},P_{q_{ij}})
\]

be a signed-pair representation of \(v\) for entry \((i,j)\), so that

\[
\boxed{
\Lambda[(P_{p_{ij}},P_{q_{ij}})]\equiv v.
}
\]

Since

\[
\Gamma(A_{ij},B_{ij})
\]

already returns a signed pair, it may be supplied directly to pair-form \(\Xi\).

Therefore define the modular matrix-sum entry by

\[
\boxed{
C_{ij}
=
\operatorname{rem}
\left(
\Xi
\left[
\Gamma(A_{ij},B_{ij}),
(P_{p_{ij}},P_{q_{ij}})
\right]
\right).
}
\]

Thus the modular matrix sum is

\[
\boxed{
A+B
=
\begin{pmatrix}
\operatorname{rem}
\left(
\Xi
\left[
\Gamma(A_{11},B_{11}),
(P_{p_{11}},P_{q_{11}})
\right]
\right)
&
\cdots
&
\operatorname{rem}
\left(
\Xi
\left[
\Gamma(A_{1n},B_{1n}),
(P_{p_{1n}},P_{q_{1n}})
\right]
\right)
\\[12pt]
\vdots
&
\ddots
&
\vdots
\\[12pt]
\operatorname{rem}
\left(
\Xi
\left[
\Gamma(A_{m1},B_{m1}),
(P_{p_{m1}},P_{q_{m1}})
\right]
\right)
&
\cdots
&
\operatorname{rem}
\left(
\Xi
\left[
\Gamma(A_{mn},B_{mn}),
(P_{p_{mn}},P_{q_{mn}})
\right]
\right)
\end{pmatrix}.
}
\]

Each entry of

\[
A+B
\]

is now a numerical symbol in

\[
\{0,1,\ldots,v-1\}.
\]

Therefore,

\[
\boxed{
A+B\in\mathbb Z_v^{m\times n}.
}
\]

The distinction is

\[
\boxed{
\overline{A+B}
=
\text{coordinate-wise signed-pair matrix addition before modulo }v
}
\]

while

\[
\boxed{
A+B
=
\text{coordinate-wise matrix addition after modulo }v.
}
\]

The type flow for each matrix entry is

\[
\boxed{
(\text{signed pair},\text{signed pair})
\overset{\Gamma}{\longrightarrow}
\text{reduced signed pair}
}
\]

followed, when modular reduction is required, by

\[
\boxed{
\text{reduced signed pair}
\overset{\Xi}{\longrightarrow}
(q,r)
\overset{\operatorname{rem}}{\longrightarrow}
r.
}
\]
